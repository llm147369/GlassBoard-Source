# GlassBoard v0.9.17 轻量回退测试版

本版修正此前音乐组件回退不彻底的问题。音乐核心恢复 v0.9.12 原实现，移除 TaskbarLyrics 核心、歌词后台及整套 .NET 8 自包含运行时。

## 安装

1. 从系统托盘退出旧版 GlassBoard。
2. 将 `GlassBoard_v0.9.17_User.zip` 完整解压到一个新文件夹，运行其中的 `GlassBoard.exe` 或 `Start.cmd`。不要只复制 EXE。
3. 原有软件清单、分组、Dock 顺序、外观 DIY、便签等继续沿用，无需删除配置。
4. 如果开启了开机自启动，请在新版“设置 → 通用”关闭再重新开启自启动，使它指向新文件夹，避免重启后又启动旧程序。

请使用新目录：覆盖解压不会自动清理旧目录里遗留的 `engine` 文件。新版不再调用它。确认新版正常后，旧版独立程序目录可以自行移走；不要删除原配置目录来升级。

## 本次具体修改

- `MediaServices.cs`、`MediaBridge.ps1`、`NativeMediaBridge.ps1` 与 v0.9.12 原文件逐字节一致，恢复自制播放、曲目信息、封面和控制逻辑。
- 音乐界面移除额外的歌词、进度条与外部引擎入口，保留上一首、播放／暂停、下一首、封面及原有本地播放操作。
- 完全移除 TaskbarLyrics 运行组件、额外词库／数据库依赖，以及 .NET 8 运行时。没有用“首次启动再下载”或“要求另装 .NET 8”替代。
- 控制中心的音频、WLAN、亮度代码迁入原 .NET Framework 4.8 程序；无线开关与蓝牙枚举通过 Windows 自带 PowerShell／WinRT 调用，不再使用旧 `engine` 后台。
- 保留控制中心小球与展开面板、图标大小设置、Win+D 处理、自启动档位、组件右键恢复、打开动画、大面板新建文件，以及 v0.9.16 的分组刷新和配置恢复保护。
- 旧版歌词设置字段仅为兼容历史配置保留，不再创建歌词窗口、轮询歌词或启动额外音乐引擎。

## 为什么之前用户包比源码大

v0.9.16 用户包约 45.17 MB，其中 `engine` 目录单独贡献约 44.32 MB 的压缩数据、包含 216 个文件；源码包没有带该目录，所以看起来反而小。此前仅恢复自制界面、仍保留后台的做法没有完全落实“回退到我们自己版本”的要求。

本版用户包只包含原轻量版的 23 个运行文件，控制中心脚本内置在主程序中，保留原有小型媒体兼容库和对应许可证。实际大小见随包更新索引。

## 验证范围

已完成 .NET Framework 4.8 主程序／更新器编译、16 组生产模型回归测试、WLAN 结构与安全配置 XML 测试、音频 COM 接口顺序检查，以及 PowerShell 协议和嵌入资源启动测试。音乐文件与 v0.9.12 的一致性、运行包清单、版本号、每个文件哈希和更新索引均有核验记录。

Linux 下的脚本测试使用模拟设备和 PowerShell 7；Windows PowerShell 5.1、真实 Wi-Fi／蓝牙／音频／亮度，以及开机和动画观感仍需 Windows 实机验收。没有声称这些硬件操作已经在 Windows 运行通过。
