# GlassBoard-Source v0.9.21.6

一个运行在 Windows 10/11 上的免费桌面启动台——毛玻璃 Dock 栏、应用面板、控制中心、桌面组件、灵动岛、壁纸引擎，一次装齐。

![桌面展示](docs/screenshot.png)

## 功能一览

- **Dock 栏**：固定常用软件，一键启动、再点最小化，多窗口自动切换置顶；悬停预览窗口列表；4 套内置图标风格，支持自定义图标与右键菜单即系统右键菜单；运行指示圆点；点击波纹动效；一键隐藏/显示桌面图标与游戏模式快捷开关。
- **应用面板**：自动收纳桌面程序；顶部系统级搜索框，开始菜单应用、注册表程序、磁盘文件流式秒出。
- **控制中心**：WiFi 连接管理、蓝牙设备管理、音量、静音、亮度、输出设备切换，连接过的 WiFi 免密直连。
- **桌面组件**：时钟（时/分/秒）、音乐组件（识别网易云、QQ 音乐、酷狗、酷我、汽水音乐等，支持播放/暂停/切歌/封面）。
- **灵动岛**：收起态显示曲目/封面/电量/通知角标/音乐频谱跳动条；展开面板含音乐页、通知页、剪贴板历史（开机存活、点击即复制）、随手记（标题/内容/提醒时间/待办/导出）、控制页；宽度/高度自由调节，跟随全局面板主题，可选置顶。
- **壁纸引擎**：本地壁纸库 + 官方图库，支持填充/适应/拉伸/居中/平铺，一键还原系统壁纸。
- **推荐配置导入**：发布包里自带 `DefaultConfig.json`，首次打开会询问"是否使用推荐配置"——只导入外观与布局设置，不覆盖图标，导入后自动改名为 `DefaultConfig.json.done`。

无广告、不联网更新、不收集任何数据，所有内容都在本地。

## 使用提示

- **音乐识别不到？** 请到音乐软件的系统设置里开启「信息同步」（系统媒体信息/播放信息同步）。音乐组件依赖系统媒体会话识别正在播放的歌曲，音乐软件关闭该同步后无法获取曲目、封面和播放状态。

## 构建

> **无需编译也能用**：仓库根目录就是编译好的便携版。拉取仓库后直接双击根目录的 `GlassBoard.exe` 即可运行，无需下载发布包，也无需安装 .NET SDK。

如需从源码构建（面向开发者）：

- 目标框架：.NET Framework 4.8（SDK 风格 csproj，WPF + WinForms，LangVersion 14）
- 依赖：`src\lib\Interop.UIAutomationClient.dll`（已随仓库提供）
- 嵌入资源：`GlassBoard.MediaBridge.ps1`、`GlassBoard.NativeMediaBridge.ps1`、`GlassBoard\ControlCenter.ps1` 及 `GlassBoard\Assets\` 下图片资源
- 发布目录需包含：`lib\NPSMLib.dll`（音乐兼容通道：进度条/拖动/封面补充，缺失时仅系统媒体会话可用）、`data\AppGroups.tsv`（应用自动分组规则）——两者均已随仓库提供，发布时一并复制到程序根目录

```powershell
dotnet build src\GlassBoard.csproj -c Release
```

## 发布说明

本仓库源码对应 v0.9.21.6（程序集版本 0.9.21.6）。仓库根目录直接存放编译好的便携版（拉取即用，双击 `GlassBoard.exe` 运行）；GitHub Release 页面同时提供便携压缩包。源码位于 `src\` 目录，仅供开发者参考与修改。

### v0.9.21.6 更新内容

- Dock 悬停放大引擎全面重写为帧驱动（15ms 渲染级定时器）：指数平滑随真实帧间隔自适应、放大方向限速 8 倍/秒、快速滑过后图标立即回落（缩小不限速），连续扫动/快甩无卡顿、无悬空
- 放大改窗口级邻近放大：光标到各图标中心的距离按平滑阶梯曲线（smoothstep）计算放大，相邻图标被局部推开——不再需要逐个图标进出动画，滑动全程连续跟手
- 修复：悬停左端会带动最右端图标（按构建顺序推邻居，视觉顺序不一致）；修复图标锚点在窗口动画期间被错误捕获导致「悬停图标不放大、悬停空白处放大」——锚点改为每帧重捕获
- 悬停放大倍数上限由 1.6 提升至 2.0，固定显示数量上限由 20 提升至 30
- 修复：强制结束进程时图标缓存可能留下半截 PNG 导致图标显示为方块（改为临时文件 + 原子替换写入，损坏文件自动删除重建）

- 修复：安装路径含中文（如 `D:\软件\...`）时，在线更新完成后无法自动重启，报「Windows 找不到文件 D:\??\GlassBoard-Source\GlassBoard.exe」且更新未落盘（根因：重启脚本按 ASCII 编码写出，非 ASCII 路径被替换成 `??`；改为路径经环境变量以 Unicode 传入，脚本本体保持纯 ASCII）
- 注意：仍在使用 0.9.21.3/0.9.21.4 且安装路径含中文的用户，本次在线更新同样会在重启阶段失败——请手动下载本包覆盖一次，之后所有在线更新恢复正常

### v0.9.21.4 更新内容

- 性能：Apple 玻璃实时模糊（LiveBlur）重捕与烘焙移出 UI 线程，避免低配机卡顿
- 性能：Dock/桌面组件/灵动岛三个玻璃窗口共享一次壁纸层捕获，静态壁纸整屏渲染结果缓存复用
- 性能：大屏（≥300 万像素区域）或软件渲染环境自动降级为静态烘焙并把实时刷新降到 5fps
- 修复：发布包补齐 data\AppGroups.tsv、DefaultConfig.json（首启推荐配置）、licenses\、说明.txt、wallpapers\（0.9.21.3 曾漏打，新装用户应用自动分组与推荐配置导入失效）
